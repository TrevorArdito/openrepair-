# ChrystalClear repair content

Team-written guides and DTC pages, one JSON file per page, in the same shape as the app's entry
kinds (see `backend/app/modules/community/kinds.py`). The seed loads them as "ChrystalClear Team"
entries after review. Research behind each page lives in `../research/`.
